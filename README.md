#  Study Vault

A comprehensive, all-in-one study platform designed for **Electronics and Communication Engineering (ECE)** students at **GCE Bargur**. This portal centralizes all the essential academic resources for the semester, making them easily accessible from a single, user-friendly dashboard.

##  Features

*   ** Semester Schedule:** Get a complete overview of the entire semester's plan.
*   ** Time Table:** View the weekly class schedule to stay on track.
*   ** Syllabus:** Access the syllabus for all 8 subjects covered in the semester.
*   ** Notes:** Download study notes, organized into 5 units per subject, including Internal Question Papers (QPs).
*   ** Lab Record PDFs:** Access PDFs for all 4 lab records.
*   ** Previous Year Papers:** Find question papers from previous years (2 papers per subject).
*   ** Responsive Design:** The dashboard is fully responsive and can be used on desktops, tablets, and mobile devices.

##  Tech Stack

This project is a modern web application built with the following technologies:

*   **Frontend:** React.js (with JSX)
*   **Build Tool:** Vite
*   **Styling:** Custom CSS with system fonts for a clean, native-like interface.
*   **Hosting:** Vercel
*   **Language:** JavaScript (ES6+)
